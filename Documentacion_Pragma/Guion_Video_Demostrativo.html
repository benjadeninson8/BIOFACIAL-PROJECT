Guion para tu Video Demostrativo

Instrucciones para ti: Sigue este guion mientras grabas tu pantalla (puedes usar OBS, Loom o Zoom). Las acciones que debes hacer en pantalla están en los recuadros grises. La idea es que te veas seguro, profesional y como el experto que blindó el proyecto.

1. Introducción y Saludo

Tú (Hablando): "Hola Carpio y equipo. Por acá [Tu Nombre] de PRAGMA STUDIO. Les grabo este video para entregarles formalmente el proyecto BioFacial, ya finalizado y completamente blindado en todas sus capas, tal como acordamos para su presentación."

Tú: "Mi objetivo hoy es mostrarles cómo quedó la seguridad del sistema, cómo funciona la biometría por debajo y cómo deben manejar ustedes la base de datos el día de su exposición para impresionar a su jurado."

2. Mostrando el Blindaje del Frontend

[Abre tu navegador y muestra la pantalla principal de BankUnerg]

Tú: "Primero, hablemos del Frontend. Para proteger la idea y el código del proyecto, implementé un blindaje anti-inspección."

[Haz clic derecho varias veces en la pantalla, intentando abrir el menú contextual]

Tú: "Como pueden ver, el menú de clic derecho está totalmente bloqueado. Además, si intento presionar las teclas de desarrollador, como F12 o Control+Shift+I [Haz el gesto de teclear o menciónalo], el sistema intercepta las teclas y bloquea el acceso. El código fuente está sellado."

[Haz scroll hacia el fondo de la página para mostrar el footer]

Tú: "Adicionalmente, en la parte inferior de todas las pantallas de BankUnerg y BodeUnerg hemos fijado el footer de autoría intelectual: 'Diseñado y desarrollado por PRAGMA STUDIO, se reserva el derecho de autor'."

3. Explicando la Seguridad del Backend (Railway)

[Puedes abrir una pestaña mostrando Railway de fondo, o simplemente dejar la pantalla de BankUnerg]

Tú: "En cuanto a nuestro servidor en la nube de Railway, no lo dejamos expuesto. Le inyecté librerías de grado bancario:
1. Helmet: Encripta las cabeceras HTTP para bloquear inyecciones de código.
2. Rate-Limiter (Antifraude): Si un atacante intenta tumbarles el servidor haciendo muchos pagos falsos de golpe, el servidor detecta el tráfico inusual y bloquea la IP automáticamente. El backend es prácticamente invulnerable."

4. La Base de Datos (Explicación del Hash y Modo Lectura)

[Abre MongoDB Atlas o Compass en la tabla 'users']

Tú: "Ahora, lo más importante: La Base de Datos. Como saben, por privacidad el sistema no guarda fotos, sino este arreglo matemático."

[Señala con el mouse el campo 'descriptor' de algún usuario, mostrando los 128 números]

Tú: "A esto se le llama Descriptor Facial de 128 dimensiones. Es como un hash de contraseña, pero biométrico. Se valida matemáticamente usando Distancia Euclidiana."

Tú: "Atención aquí: Yo les he creado a ustedes un usuario especial de 'Solo Lectura'. Les pasaré las credenciales de este usuario junto con el Manual Técnico. El día de su defensa, abran MongoDB con esas credenciales. Así podrán mostrarle al jurado en tiempo real cómo se llenan los datos de las personas, pero ni ustedes ni el jurado podrán borrar o dañar la base de datos por accidente. Es la forma más profesional de hacer una demostración."

5. Demostración Rápida del Flujo

[Ve a BankUnerg y registra un usuario falso rápidamente usando tu rostro]

Tú: "Para cerrar, hagamos una prueba. Me registro en BankUnerg, el sistema extrae mis puntos faciales en el navegador (no en la nube, lo que ahorra costos) y me genera un código de éxito."

[Pásate a la pestaña de BodeUnerg, agrega algo al carrito y paga con Reconocimiento Facial]

Tú: "Luego, en el kiosco BodeUnerg, el usuario va a pagar. Escoge biometría, el sistema lee mi rostro, calcula la distancia euclidiana matemática contra la base de datos en milisegundos, aprueba el pago porque la similitud es exacta, y listo. Sin tarjetas, sin efectivo."

6. Despedida

Tú: "Con esto cerramos. El proyecto está 100% operativo y en producción. Lean el Manual Técnico de Cliente que les envié, ahí está toda esta teoría explicada para que sepan defenderse ante cualquier pregunta. Un abrazo y mucho éxito en la defensa."
